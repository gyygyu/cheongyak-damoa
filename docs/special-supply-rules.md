# 특별공급 판정 근거 (Plan B 조사, 2026-11-07)

출처: 법제처 국가법령정보센터, 「주택공급에 관한 규칙」 [시행 2026. 6. 15.] 국토교통부령 제1592호. 아래는 판정에 쓰는 요건만 줄여 적은 것 — 원문은 법제처에서 확인.
"소득 N%" = 전년도 도시근로자 가구당 월평균 소득의 N%. "재산 대안" = 소득 초과 시 부동산 가액 합계가 건보 재산등급 29등급 하한·상한 평균 이하이면 가능(사이트는 확인 필요로 둠).

- 배정 순서(우선공급 소득 구간): 신혼 ③·⑥ 50% 100%(맞벌이 120%) → 20% 140%(160%) → 나머지 추첨. 신생아 국민 50% 100% → 20% 130%, 민영 50% 130% → 20% 160%. 생애최초 국민 50% 100% → 20% 130%, 민영 50% 130% → 20% 160%.

## 공통
- 제48조 저축: 제35조의3·제40조·제41조(그 밖에 기관추천 등)는 국민 = 가입 6개월 + 6회 이상 납입, 민영 = 가입 6개월 + 별표 2 예치기준금액. 제43조·제46조는 1순위 요건으로 갈음.
- 제55조: 제35조~제49조 특별공급은 한 차례(1세대 1주택). 일부 기관추천 등은 예외.
- 제55조의3 ③: 2024. 6. 19. 이후 출생 자녀(태아·그 이후 출생자 입양 포함)가 있으면 **제35조의3·제40조·제41조·제46조**를 한 차례 더 신청 가능(생애최초 제43조는 해당 없음). 본인·배우자가 주택을 소유해도(다른 세대원 소유 제외) 이 특례 신청 가능 — 단 기존 주택 처분 조건(⑤).
- 제55조의3 ①·②: 배우자의 혼인 전 당첨·소유 사실, 본인의 혼인 전 당첨 사실은 신혼·신생아(생애최초는 배우자 소유 이력 포함) 신청을 막지 않음.

## 사이트 판정에서 "확인 필요"로 두는 것
1순위 여부, 예치금(별표 2), 재산 대안, 제18조 사업주체 여부(공고에 공공 사업주체 표시가 없을 때), 소득 기준표가 없는 해, 기관추천·비수도권·지역균형·철거주택(안내만).
